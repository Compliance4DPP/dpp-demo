DPP metadata check

An AAS file is sent to Open Policy Agent; a Rego policy checks it against IDTA 02099-1 §3.1 (mandatory attributes, types, date-time with timezone).

Policy: policy/dpp.rego · Checked against: IDTA 02099-1 v1.0 §3.1, submodel admin-shell.io/idta/cds/dppMetadata/1

Pick a sample or paste an AAS file, then check. The result appears here.

Because the check passed, the service issued a verifiable credential: a signed statement that this DPP passed the check. Anyone can verify it against the issuer's public key, without running the check again.
